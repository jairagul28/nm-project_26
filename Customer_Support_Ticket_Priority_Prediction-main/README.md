# Customer Support Ticket Priority Prediction and Automated Assignment System Using Agentforce

## Project Overview

This project is a Salesforce-based customer support ticket management system developed using Agentforce. It helps manage customer support tickets, analyze ticket details, determine ticket priority, and support automated ticket assignment.

## Objective

The main objective of this project is to improve customer support ticket management by reducing manual work and helping support teams handle important tickets efficiently.

## Technologies Used

- Salesforce
- Agentforce
- Salesforce Flow
- Lightning App
- Custom Objects and Fields

## Key Features

- Customer support ticket creation and management
- Customer and contact information management
- Ticket priority prediction
- Automated ticket assignment
- Agentforce-based AI assistance
- Subagent configuration
- Agent Actions
- Salesforce Flow automation

## Project Components

- Support Ticket Intelligence custom object
- Custom fields for ticket information
- Salesforce Flow
- Agentforce Agent
- Agentforce Subagent
- Agent Actions
- Automated ticket assignment

## Project Workflow

1. Create a customer support ticket.
2. Enter customer and issue details.
3. Agentforce analyzes the ticket information.
4. The ticket priority is determined.
5. The ticket is assigned appropriately.
6. Support tickets are monitored and managed through Salesforce.

## Project Outcome

The system helps streamline customer support operations, reduce manual ticket handling, and improve the management of support requests.
